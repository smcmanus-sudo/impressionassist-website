Security & Compliance

Radiology data is among the most sensitive information in healthcare, and ImpressionAssist is built around that reality. We designed the product so that protected health information is processed in memory and never stored, transmitted only over encrypted channels, and handled under a Business Associate Agreement with our cloud provider. The details below reflect how the system is architected and operated today.

Security Controls

Built for healthcare IT requirements from day one.

HIPAA Compliant Yes
BAA with Google Yes
PHI Storage None—data processed in memory, never stored
Data Retention None—no patient data retained after processing
Audit Logging Yes (PHI-safe)
LLM Provider Google Vertex AI (Gemini)
Data Residency United States
Subprocessors Google Cloud (Vertex AI)
Encryption TLS 1.2+ for all data in transit
Authentication Organization-level API keys
Deployment Windows 10/11, MSI installer
Integration PowerScribe One (native fill-in field)
